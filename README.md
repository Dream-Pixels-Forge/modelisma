# modelisma

African fashion platform showcasing editorial, collections, and talent.

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS 4
- GSAP + ScrollTrigger
- Lenis smooth scroll

## Getting Started

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Deploy

Deploy to Vercel: https://vercel.com/new
